# 🎵 BiasBox

A modern K-pop themed website built with **Next.js** and **Tailwind CSS** that showcases a fictional monthly subscription box service for K-pop fans. BiasBox allows users to explore subscription plans, discover what comes inside each box, learn about the company, and contact the team through a clean, responsive interface.

---

## 📖 Project Overview

BiasBox is a promotional website for a fictional K-pop subscription box service. The project was created to practice building a multi-page application using the Next.js App Router while implementing reusable layouts, components, and responsive styling with Tailwind CSS.

The website includes:

- Shared navigation and footer across every page
- Responsive layouts
- Modern Tailwind CSS styling
- Multiple pages using the Next.js App Router
- Reusable React components

---

## ✨ Features

- 🏠 Home page introducing BiasBox

## 📄 Pages

### 🏠 Home

Introduces BiasBox with a hero section, featured highlights, and calls to action encouraging users to learn more about the subscription service.

### 📦 What's Inside

Displays the different collectibles included in each monthly BiasBox, including:

Allows visitors to compare three subscription tiers:

- Idol

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/yourusername/biasbox.git
```

### Navigate into the project

```bash
cd biasbox
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```
